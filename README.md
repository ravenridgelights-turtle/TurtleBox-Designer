# TurtleBox Designer

**Windows: download only [Setup.exe from the latest release](https://github.com/ravenridgelights-turtle/TurtleBox-Designer/releases/latest).**

Design enclosures and mounting plates for pixel-light controllers. Arrange controllers and power supplies in 2D and 3D, route wires and pigtails, build stacked plates, get a parts list, and export laser SVGs, drilling templates, and printable plates.

Use **Updates** beside the turtle inside TurtleBox Designer to read what changed, save your project, and install an update in place. You do not need a GitHub account to download or update the app.

This repository hosts public installers, release notes, screenshots and issue reports. Development source and its history are maintained separately. The automatically generated “Source code” archives on release pages contain this download site's files; use the **Setup.exe** asset to install the application.

## Help and feedback

[Report a problem](https://github.com/ravenridgelights-turtle/TurtleBox-Designer/issues) with your installed version and the steps that reproduce it. Share a small demonstration project when possible. Remove personal information before posting files publicly.

## Project files

Before updating, use **Save project** or **Save project & install update**. Installer updates preserve the dedicated TurtleBox workspace and projects. Keep backups of your `.tbox.json` projects.

Existing releases retain their original license and third-party notices inside the downloaded packages. Making the development repository private does not recall copies previously distributed.
